PCA Functions

Principal Component Analysis with the NIPALS algorithm (#include <scientific.h>). Typical workflow: NewPCAModel() → PCA() → read the members of PCAMODEL or PCAScorePredictor() for new objects → DelPCAModel().

struct PCAMODEL
[source]

Principal Component Analysis model.

Create it with NewPCAModel(), fill it with PCA() and free it with DelPCAModel(). All the members are allocated and owned by the model: read them, but do not free or resize them.

With n objects (rows), f features (columns) and npc components:

matrix *scores
[source]

Scores T, n x npc: coordinates of each object in the component space.

matrix *loadings
[source]

Loadings P, f x npc: weight of each feature in each component. Each column has unit length.

matrix *dmodx
[source]

Distance of each object to the model, n x npc: element [i][k] is the norm of the residual of object i after removing components 0..k.

dvector *varexp
[source]

Variance explained by each component, in percent of the total variance of the preprocessed matrix (size npc, not cumulative).

dvector *colaverage
[source]

Column means of the training matrix (size f).

dvector *colscaling
[source]

Column scaling factors (size f; all 1 for scaling 0).

void PCA(matrix *mx, int scaling, size_t npc, PCAMODEL *model, scisignal *s)
[source]

Fit a PCA model with the NIPALS algorithm.

The columns of mx are preprocessed according to scaling, then the npc components are extracted one at a time. Each component gets up to 1000 NIPALS iterations; a component that does not converge keeps its best estimate. Missing values (MISSING, NaN, inf) are skipped.

Parameters:

  • mx – [in] Training matrix, n x f (objects x features). Not modified, except that NaN/inf values are replaced by MISSING.

  • scaling – [in] Column preprocessing. All the options mean-center the columns, then: 0 = no scaling, 1 = standard deviation (autoscaling), 2 = root mean square, 3 = Pareto (square root of the standard deviation), 4 = range (max - min), 5 = level (column mean).

  • npc – [in] Number of components to compute; capped to f.

  • model – [out] Model created with NewPCAModel(). Its members are resized and filled with the results (see PCAMODEL).

  • s – [in] Optional stop signal: when *s == SIGSCIENTIFICSTOP the computation stops after the current component. Pass NULL if unused.

Returns:

Nothing, the results are written into model.

Example

matrix *x;
PCAMODEL *model;
NewMatrix(&x, 5, 3);          // 5 objects, 3 features
// ... fill x->data[i][j] ...
NewPCAModel(&model);
PCA(x, 1, 2, model, NULL);    // autoscaling, 2 components
// model->scores: 5 x 2, model->loadings: 3 x 2,
// model->varexp->data[k]: % of variance of component k
DelPCAModel(&model);
DelMatrix(&x);
void PCAScorePredictor(matrix *mx, PCAMODEL *model, size_t npc, matrix *pscores)
[source]

Project new objects into a fitted PCA model.

The objects are preprocessed with the column means and scalings of the training data, then projected onto the loadings. Projecting the training matrix gives the same values as model->scores.

Parameters:

  • mx – [in] Objects to project, m x f, with the same features (same order) as the training matrix.

  • model – [in] Model fitted with PCA().

  • npc – [in] Number of components to use; capped to the model components.

  • pscores – [out] Matrix created with initMatrix or NewMatrix. It is resized and filled with the predicted scores, m x npc. The caller frees it with DelMatrix.

Returns:

Nothing, the scores are written into pscores.

Example

matrix *pscores;
initMatrix(&pscores);
PCAScorePredictor(xnew, model, 2, pscores);   // xnew: m x f
// pscores->data[i][k]: score of new object i on component k
DelMatrix(&pscores);
void PCAIndVarPredictor(matrix *t, matrix *p, dvector *colaverage, dvector *colscaling, size_t npc, matrix *mx)
[source]

Rebuild data in the original feature space from scores: X = T P'.

The product of the first npc scores and loadings is computed, then the scaling and centering are reverted, so the result is in the units of the training data. With all the components the training matrix is rebuilt exactly.

Parameters:

  • t – [in] Scores, n x a with a >= npc (e.g. model->scores or the output of PCAScorePredictor()).

  • p – [in] Loadings, f x a (model->loadings).

  • colaverage – [in] Column means, size f (model->colaverage).

  • colscaling – [in] Column scalings, size f (model->colscaling).

  • npc – [in] Number of components to use; capped to the columns of t.

  • mx – [out] Matrix created with initMatrix; resized and filled with the reconstructed data, n x f. The caller frees it with DelMatrix.

Returns:

Nothing, the result is written into mx.

void PCARSquared(matrix *mx, PCAMODEL *model, size_t npc, dvector *r2)
[source]

Compute how well a model reconstructs a matrix (R²) for 1..npc components.

For each number of components a = 1..npc the objects of mx are projected and reconstructed with a components, and R²(a) = 1 - SS(residual) / SS(mx centered on the model column means) is appended to r2. The values are cumulative: r2[a-1] refers to the first a components together.

Parameters:

  • mx – [in] Matrix to reconstruct, n x f (training data or new objects).

  • model – [in] Model fitted with PCA().

  • npc – [in] Maximum number of components; capped to the model components.

  • r2 – [out] Empty vector created with initDVector: npc values are appended to it. The caller frees it with DelDVector.

Returns:

Nothing, the values are appended to r2.

void PCARankValidation(matrix *mx, size_t npc, size_t scaling, size_t group, size_t iterations, dvector *r2, scisignal *s)
[source]

Estimate the number of significant components by cross-validation.

The objects are split at random into group groups. Each group in turn is left out, a PCA model is fitted on the other objects and PCARSquared() is computed on the left-out group. The procedure is repeated iterations times and the results are averaged, giving the cross-validated R² (Q²) for 1..npc components (S. Wold, Technometrics 20, 397-405, 1978). Choose the number of components where Q² stops increasing. The random split is deterministic for a given input size.

Parameters:

  • mx – [in] Data matrix, n x f.

  • npc – [in] Maximum number of components to evaluate.

  • scaling – [in] Column preprocessing, as in PCA().

  • group – [in] Number of cross-validation groups (e.g. 5 or 7).

  • iterations – [in] Number of random repetitions of the split.

  • r2 – [out] Empty vector created with initDVector: receives npc values, element a-1 being Q² with a components.

  • s – [in] Optional stop signal (see PCA()); NULL if unused.

Returns:

Nothing, the values are written into r2.

void PCATsqContributions(matrix *x, PCAMODEL *model, size_t npc, dvector *spe, matrix *contributions)
[source]

Compute the squared prediction error (SPE) of each object and its per-feature contributions.

Despite the name, the statistic is the SPE (Q residual), not Hotelling’s T². Each object is projected and reconstructed with npc components; the residuals are computed in the preprocessed (centered and scaled) space. contributions[i][j] is the squared residual of feature j for object i and spe[i] is their sum. Large values identify objects (and the features responsible) that the model does not describe well.

Parameters:

  • x – [in] Objects to evaluate, n x f.

  • model – [in] Model fitted with PCA().

  • npc – [in] Number of components of the model to use.

  • spe – [out] Vector created with initDVector; resized to n.

  • contributions – [out] Matrix created with initMatrix; resized to n x f.

Returns:

Nothing, the results are written into spe and contributions.

void GetResidualMatrix(matrix *mx, PCAMODEL *model, size_t pc, matrix *rmx)
[source]

Compute the residual matrix of the training data after pc components.

Returns E = X_preprocessed - T P' using the first pc components. It uses the training scores stored in the model, so mx must be the same matrix used to fit the model; for new objects use PCAScorePredictor() and PCAIndVarPredictor().

Parameters:

  • mx – [in] The training matrix, n x f.

  • model – [in] Model fitted on mx with PCA().

  • pc – [in] Number of components to remove; capped to f.

  • rmx – [out] Matrix created with initMatrix; resized and filled with the residuals in the preprocessed (centered and scaled) space, n x f.

Returns:

Nothing, the residuals are written into rmx.

void PrintPCA(PCAMODEL *m)
[source]

Print the explained variance, scores, loadings and DModX of a model to standard output.

Parameters:

  • m – [in] The model to print.

Complete example (docs/c_code_examples/pcaexample1.c):

#include <stdio.h>
#include <scientific.h>

int main(void)
{
    matrix *m; // Definition of the input matrix
    PCAMODEL *model; // Definition of the PCA model
    int i, j;
    int nobj = 20;
    int nvars = 8;
    NewMatrix(&m, nobj, nvars);

    // Fill with random values the matrix m
    srand(nobj);
    for(size_t i = 0; i < nobj; i++){
        for(size_t j = 0; j < nvars; j++){
            m->data[i][j] = randDouble(0,20);
        }
    }


    NewPCAModel(&model); // Allocation of the PCA model
    PCA(m, 1, 5, model, NULL); // Calculation of the PCA on matrix m using unit variance scaling (1) and the extraction of 5 principal components

    PrintPCA(model); // Print to video the PCA results

    /* Of course you can print in a separate way the different results contained in the model variable
     * model->scores is the matrix of scores
     * model->loadings is the matrix of loadings
     * model->colavg is the column average obtained from the input matrix
     * model->scaling is the scaling factor obtained from the input matrix
     */

    // Free the memory spaces
    DelPCAModel(&model);
    DelMatrix(&m);
}

CPCA Functions

Consensus (multi-block) Principal Component Analysis. The blocks are the layers of a tensor, all with the same objects (rows). Workflow: NewCPCAModel() → CPCA() → CPCAScorePredictor() → DelCPCAModel().

struct CPCAMODEL
[source]

Consensus Principal Component Analysis model (multi-block PCA).

Create it with NewCPCAModel(), fill it with CPCA() and free it with DelCPCAModel(). All the members are owned by the model. With n objects, B blocks (block b has f_b columns) and npc components:

tensor *block_scores
[source]

One n x B matrix per component (block_scores->m[k]): column b holds the scores of block b on component k.

tensor *block_loadings
[source]

One f_b x npc matrix per block (block_loadings->m[b]).

matrix *super_scores
[source]

Consensus scores, n x npc. They equal the PCA scores of the concatenated blocks, each divided by sqrt(f_b).

matrix *super_weights
[source]

Contribution of each block to each component, B x npc (unit-length columns).

dvector *scaling_factor
[source]

Block scaling sqrt(f_b) of each block (size B).

dvector *total_expvar
[source]

Percentage of the total variance explained by each component (size npc, not cumulative).

dvectorlist *block_expvar
[source]

One vector of size B per component: the cumulative percentage of the variance of each block explained so far.

dvectorlist *colaverage
[source]

Column means of each block (one vector per block).

dvectorlist *colscaling
[source]

Column scalings of each block (one vector per block).

void CPCA(tensor *x, int scaling, size_t npc, CPCAMODEL *model)
[source]

Fit a Consensus PCA model on a set of blocks.

Every block is preprocessed column by column according to scaling and divided by sqrt(f_b); the consensus components are then extracted one at a time (Westerhuis, Kourti and MacGregor, J. Chemometrics 12, 301-321, 1998), with up to 1000 iterations per component. Fitting an already fitted model replaces its results.

Parameters:

  • x – [in] The blocks: one tensor matrix per block (x->m[b], n x f_b), all with the same rows in the same object order.

  • scaling – [in] Column preprocessing: 0 = mean centering only, 1 = standard deviation, 2 = root mean square, 3 = Pareto, 4 = range, 5 = level.

  • npc – [in] Number of components; capped to the columns of the smallest block.

  • model – [out] Model created with NewCPCAModel(); filled with the results (see CPCAMODEL).

Returns:

Nothing, the results are written into model.

Example

tensor *blocks;
CPCAMODEL *model;
NewTensor(&blocks, 2);
NewTensorMatrix(blocks, 0, 20, 10);   // block 0: 20 objects x 10 columns
NewTensorMatrix(blocks, 1, 20, 7);    // block 1: 20 objects x 7 columns
// ... fill blocks->m[b]->data[i][j] ...
NewCPCAModel(&model);
CPCA(blocks, 1, 3, model);
// model->super_scores: 20 x 3, model->super_weights: 2 x 3
DelCPCAModel(&model);
DelTensor(&blocks);

void PrintCPCA(CPCAMODEL *m)

Print the content of a CPCA model to standard output.

  • m – [in] The model to print.

Complete example (docs/c_code_examples/cpcaexample1.c):

#include <stdio.h>
#include <scientific.h>

int main(void)
{
    tensor *t; // Definition of the input tensor
    CPCAMODEL *model; // Definition of the CPCA model

    int nblocks = 4;
    int nobj = 20;

    NewTensor(&t, nblocks);

    for(k = 0; k < nblocks; k++){
        NewTensorMatrix(t, k, nobj, nvars[k]);
        for(i = 0; i < nobj; i++){

            }
        }

    CPCA(t, 1, 5, model); // Calculation of the CPCA on matrix m using unit variance scaling (1) and the extraction of 5 super principal components

    PrintCPCA(model); // Print to video the CPCA results

    /* Of course you can print in a separate way the different results contained in the model variable
     * model->super_scores is the matrix of super scores
     * model->super_weights is the matrix of super weights
     * model->block_scores is the tensor of scores for each block
     * model->block_loadings is the tensor of loadings for each block

    DelCPCAModel(&model);
    DelTensor(&t);
}

PLS Functions

Workflow: NewPLSModel() → PLS() → PLSYPredictorAllLV() (or PLSScorePredictor() + PLSYPredictor()) → DelPLSModel(). /* Multi-way PCA: 15 objects x 4 features measured in 3 conditions (layers). */
#include <stdio.h>
#include <math.h>
#include <scientific.h>

int main(void)
{
    tensor *X, *Xr;
    matrix *pscores;
    UPCAMODEL *model;
    size_t i, j, k;

    NewTensor(&X, 3);
    for(k = 0; k < 3; k++){
        NewTensorMatrix(X, k, 15, 4);   /* every layer: 15 objects x 4 features */
        for(i = 0; i < 15; i++)
            for(j = 0; j < 4; j++)
                X->m[k]->data[i][j] = 3.0 * (double)(j + 1)
                    + sin(0.9 * (double)(i + 1)) * (1.0 + 0.5 * (double)j) * (1.0 + 0.7 * (double)k);
    }

    NewUPCAModel(&model);
    UPCA(X, 1, 1, model, NULL);   /* 1 component, autoscaling */
    printf("explained variance: %.2f%%\n", model->varexp->data[0]);
    printf("loading matrix of component 0: %zu features x %zu layers\n",
           model->loadings->m[0]->row, model->loadings->m[0]->col);

    initMatrix(&pscores);
    UPCAScorePredictor(X, model, 1, pscores);
    printf("score of object 0: %.4f (model %.4f)\n", pscores->data[0][0], model->scores->data[0][0]);

    initTensor(&Xr);
    UPCAIndVarPredictor(model->scores, model->loadings, model->colaverage, model->colscaling, 1, Xr);
    printf("X[0][0][0] = %.4f, reconstructed %.4f\n", X->m[0]->data[0][0], Xr->m[0]->data[0][0]);

    DelTensor(&Xr);
    DelMatrix(&pscores);
    DelUPCAModel(&model);
    DelTensor(&X);
