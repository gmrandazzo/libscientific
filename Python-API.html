Python API Reference

Every model follows the same pattern:

model = PCA(scaling=1, npc=2)     # 1. create with the options
model.fit(X)                      # 2. fit on training data
scores = model.predict(X_new)     # 3. use on new data
model.save("model.lsm")           # 4. save / load

Inputs can be Python lists of rows, numpy arrays or Matrix objects (see MatrixLike). Results are Python lists: the documentation of every method gives their exact shape. Wrap them with numpy.array(...) if you need arrays.

The examples in the documentation are executed by the test suite, so they always match the behaviour of the library.
