CPCA — Consensus (multi-block) PCA

Consensus Principal Component Analysis (CPCA), a multi-block PCA.

CPCA analyses several blocks of variables measured on the same objects (for example spectra from different instruments, or different groups of descriptors). Every block is a matrix with the same rows (objects) and its own columns (features). The model finds:

  • super scores (n_objects x npc): a consensus description of the objects common to all the blocks. They equal the PCA scores of the concatenated blocks, each block scaled by 1/sqrt(n_columns);

  • super weights (n_blocks x npc): how much each block contributes to each component;

  • block scores and block loadings: the description of each block.

Algorithm: Westerhuis, Kourti and MacGregor, Analysis of multiblock and hierarchical PCA and PLS models, J. Chemometrics 12, 301-321 (1998).

Most users only need the CPCA class:

>>> from libscientific.cpca import CPCA
>>> block1 = [[1.0, 2.0, 3.0], [2.0, 1.0, 4.0], [3.0, 4.0, 2.0],
...           [4.0, 3.0, 1.0], [5.0, 5.0, 0.5], [6.0, 4.0, 2.5]]
>>> block2 = [[0.5, 1.0], [1.5, 0.5], [1.0, 2.5],
...           [2.5, 1.5], [2.0, 3.0], [3.5, 2.0]]
>>> model = CPCA(scaling=1, npc=2).fit([block1, block2])
>>> [round(v, 2) for v in model.get_total_exp_variance()]
[70.31, 24.68]

The functions after the class are the low-level ctypes wrappers of the C API.

class libscientific.cpca.CPCA(scaling: int = 1, npc: int = 2)

Consensus Principal Component Analysis model.

Parameters:

  • scaling (int, default 1) – Column preprocessing applied to every block. All options mean-center the columns, then: 0 = no scaling, 1 = unit variance (autoscaling), 2 = root mean square, 3 = Pareto, 4 = range, 5 = level (see PCA). After the column scaling each block is also divided by sqrt(n_columns) so that large blocks do not dominate.

  • npc (int, default 2) – Number of components. It is capped to the number of columns of the smallest block: after fit(), npc holds the number of components actually computed.

scaling

The preprocessing option given at construction.

Type:

int

npc

Number of components of the model.

Type:

int

model

The underlying C model (low-level access, see CPCAMODEL).

Type:

ctypes.POINTER(CPCAMODEL)

Notes

  • The input is a list of blocks. Every block is a matrix (list of rows or 2D numpy array) and all the blocks must have the same number of rows, in the same object order. A Tensor is also accepted.

  • The sign of each component is arbitrary.

Examples

>>> block1 = [[1.0, 2.0, 3.0], [2.0, 1.0, 4.0], [3.0, 4.0, 2.0],
...           [4.0, 3.0, 1.0], [5.0, 5.0, 0.5], [6.0, 4.0, 2.5]]
>>> block2 = [[0.5, 1.0], [1.5, 0.5], [1.0, 2.5],
...           [2.5, 1.5], [2.0, 3.0], [3.5, 2.0]]
>>> model = CPCA(scaling=1, npc=2)
>>> model.fit([block1, block2])
CPCA(scaling=1, npc=2)
>>> len(model.get_super_scores()), len(model.get_super_scores()[0])  # 6 objects x 2 PCs
(6, 2)
>>> [[round(v, 2) for v in pc] for pc in model.get_block_expvar()]   # cumulative % per block
[[80.09, 60.53], [91.57, 98.4]]
>>> super_scores, block_scores = model.predict([block1[:2], block2[:2]])  # 2 new objects
>>> len(super_scores), len(super_scores[0])
(2, 2)
fit(t_input: Sequence[libscientific.matrix.MatrixLike] | Any) → CPCA

Compute the consensus components of a set of blocks.

Calling fit again replaces the previous model.

Parameters:

t_input (list of MatrixLike, or Tensor) – The blocks: [block_0, block_1, ...], block b with shape (n_objects, n_columns_b). All blocks have the same rows.

Returns:

The fitted model itself, so calls can be chained: CPCA(npc=2).fit(blocks).

Return type:

CPCA

get_super_scores() → list[list[float]]

Return the super (consensus) scores of the training objects.

Returns:

Matrix of shape (n_objects, npc): the position of each object in the space shared by all the blocks.

Return type:

list[list[float]]

get_super_weights() → list[list[float]]

Return the super weights: the contribution of each block to each component.

Returns:

Matrix of shape (n_blocks, npc). Each column has unit length; a large value means that the block drives that component.

Return type:

list[list[float]]

Examples

>>> block1 = [[1.0, 2.0, 3.0], [2.0, 1.0, 4.0], [3.0, 4.0, 2.0],
...           [4.0, 3.0, 1.0], [5.0, 5.0, 0.5], [6.0, 4.0, 2.5]]
>>> block2 = [[0.5, 1.0], [1.5, 0.5], [1.0, 2.5],
...           [2.5, 1.5], [2.0, 3.0], [3.5, 2.0]]
>>> w = CPCA(npc=2).fit([block1, block2]).get_super_weights()
>>> len(w), len(w[0])            # 2 blocks x 2 components
(2, 2)
>>> round(w[0][0] ** 2 + w[1][0] ** 2, 6)
1.0
get_block_scores() → list[list[list[float]]]

Return the block scores of the training objects, grouped by component.

Returns:

npc matrices, one per component. Matrix k has shape (n_objects, n_blocks): column b holds the scores of block b on component k. So get_block_scores()[k][i][b] is the score of object i in block b on component k.

Return type:

list[list[list[float]]]

get_block_loadings() → list[list[list[float]]]

Return the loadings of each block.

Returns:

n_blocks matrices, one per block. Matrix b has shape (n_columns_b, npc): the weight of each feature of block b in each component.

Return type:

list[list[list[float]]]

get_block_expvar() → list[list[float]]

Return the variance of each block explained by the model, in percent.

Returns:

npc rows, one per component, with n_blocks values each: element [k][b] is the cumulative percentage of the variance of block b explained by components 0..k.

Return type:

list[list[float]]

get_total_exp_variance() → list[float]

Return the percentage of the total variance explained by each component.

Returns:

npc values, one per component (not cumulative).

Return type:

list[float]

predict(t_input: Sequence[libscientific.matrix.MatrixLike] | Any) → tuple[list[list[float]], list[list[list[float]]]]

Project new objects into the model.

Parameters:

t_input (list of MatrixLike, or Tensor) – The blocks of the new objects, with the same number of blocks and columns, in the same order, as the training data. Every block has n_new_objects rows.

Returns:

  • super_scores (list[list[float]]) – Shape (n_new_objects, npc).

  • block_scores (list[list[list[float]]]) – npc matrices of shape (n_new_objects, n_blocks), same layout as get_block_scores().

Notes

Projecting the training objects reproduces get_super_scores() within the convergence tolerance of the algorithm (about 1e-5).

save(filepath: str) → None

Save the model to a file.

Parameters:

filepath (str) – Destination path. .sqlite3 or .db use the legacy SQLite format; any other extension (.lsm recommended) uses the binary libscientific model container.

Raises:

OSError – If the file cannot be written.

load(filepath: str) → None

Load a model saved with save(), replacing the current one.

The format is detected from the file content or the extension. After loading, npc is set to the number of stored components.

Parameters:

filepath (str) – Path of the model file.

Raises:

OSError – If a binary model file cannot be read.

Examples

>>> import os, tempfile
>>> block1 = [[1.0, 2.0, 3.0], [2.0, 1.0, 4.0], [3.0, 4.0, 2.0],
...           [4.0, 3.0, 1.0], [5.0, 5.0, 0.5], [6.0, 4.0, 2.5]]
>>> block2 = [[0.5, 1.0], [1.5, 0.5], [1.0, 2.5],
...           [2.5, 1.5], [2.0, 3.0], [3.5, 2.0]]
>>> model = CPCA(npc=2).fit([block1, block2])
>>> path = os.path.join(tempfile.mkdtemp(), "cpca.lsm")
>>> model.save(path)
>>> loaded = CPCA()
>>> loaded.load(path)
>>> loaded.npc, loaded.predict([block1, block2]) == model.predict([block1, block2])
(2, True)

Low-level API

Thin ctypes wrappers around the C functions, working on raw C pointers. They are needed only to interoperate with other low-level code.

class libscientific.cpca.CPCAMODEL

C structure holding a fitted CPCA model (low-level API).

Use CPCA instead of accessing this structure directly. With n objects, B blocks (block b has f_b columns) and npc components:

block_scores

One n x B matrix per component: column b holds the block scores of block b.

Type:

POINTER(TENSOR)

block_loadings

One f_b x npc matrix per block.

Type:

POINTER(TENSOR)

super_scores

Consensus scores, n x npc.

Type:

POINTER(MATRIX)

super_weights

Block weights, B x npc (each column has unit length).

Type:

POINTER(MATRIX)

scaling_factor

Block scaling factor sqrt(f_b) of each block.

Type:

POINTER(DVECTOR)

total_expvar

Percentage of the total variance explained by each component.

Type:

POINTER(DVECTOR)

block_expvar

For each component, the cumulative percentage of the variance of each block explained by the components up to that one.

Type:

POINTER(DVECTLIST)

colaverage, colscaling

Column means and scalings of each block.

Type:

POINTER(DVECTLIST)
