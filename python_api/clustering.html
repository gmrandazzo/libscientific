Clustering and object selection

Object selection and clustering.

  • most_descriptive_compound() and max_dissimilarity_selection() pick a representative subset of objects (rows), e.g. to build a diverse training set;

  • k_means_pp_centers() picks well spread starting centers;

  • k_means_plus_plus() assigns every object to one of k clusters.

All functions accept a list of rows, a numpy array or a Matrix, and work on multiple threads (nthreads defaults to the number of CPUs).

Distance metrics (metric): 0 = euclidean, 1 = manhattan, 2 = cosine (1 - cosine similarity).

>>> from libscientific.clustering import max_dissimilarity_selection
>>> X = [[0.0, 0.0], [0.1, 0.0], [5.0, 5.0], [5.1, 5.0], [0.0, 5.0], [10.0, 0.0]]
>>> sorted(max_dissimilarity_selection(X, 3))   # 3 far apart objects
[3, 4, 5]

Functions

libscientific.clustering.most_descriptive_compound(x_input: libscientific.matrix.MatrixLike, nobjects: int, metric: int = 0, nthreads: int | None = None) → list[int]

Select the most descriptive objects (MDC algorithm).

The first selected object is the one closest to all the others (the most representative); each following object is the one that best describes the objects not yet represented by the selection.

Parameters:

  • x_input (MatrixLike) – Data, shape (n_objects, n_features).

  • nobjects (int) – Number of objects to select (at most n_objects).

  • metric (int, default 0) – Distance: 0 = euclidean, 1 = manhattan, 2 = cosine.

  • nthreads (int, optional) – Number of threads (default: number of CPUs).

Returns:

Row indexes of the selected objects, in selection order.

Return type:

list[int]

See also

most_descriptive_compound_fast

same selection, lower memory use.

Examples

>>> X = [[0.0, 0.0], [0.1, 0.0], [0.2, 0.1], [5.0, 5.0], [5.1, 5.0]]
>>> ids = most_descriptive_compound(X, 2)
>>> len(ids), len(set(ids))
(2, 2)
libscientific.clustering.most_descriptive_compound_fast(x_input: libscientific.matrix.MatrixLike, nobjects: int, metric: int = 0, nthreads: int | None = None) → list[int]

Memory-efficient version of most_descriptive_compound().

The distances are computed on the fly instead of being stored, so it works on data sets that do not fit an n_objects x n_objects distance matrix in memory. It selects the same objects as most_descriptive_compound().

Parameters:

  • x_input (MatrixLike) – Data, shape (n_objects, n_features).

  • nobjects (int) – Number of objects to select.

  • metric (int, default 0) – Distance: 0 = euclidean, 1 = manhattan, 2 = cosine.

  • nthreads (int, optional) – Number of threads (default: number of CPUs).

Returns:

Row indexes of the selected objects, in selection order.

Return type:

list[int]

libscientific.clustering.max_dissimilarity_selection(x_input: libscientific.matrix.MatrixLike, nobjects: int, metric: int = 0, nthreads: int | None = None) → list[int]

Select objects as different as possible from each other (MaxMin).

Each new object is the one whose distance to the closest already selected object is the largest, which spreads the selection over the whole data space (including outliers).

Parameters:

  • x_input (MatrixLike) – Data, shape (n_objects, n_features).

  • nobjects (int) – Number of objects to select.

  • metric (int, default 0) – Distance: 0 = euclidean, 1 = manhattan, 2 = cosine.

  • nthreads (int, optional) – Number of threads (default: number of CPUs).

Returns:

Row indexes of the selected objects, in selection order.

Return type:

list[int]

Examples

>>> X = [[0.0, 0.0], [0.1, 0.0], [5.0, 5.0], [5.1, 5.0], [0.0, 5.0], [10.0, 0.0]]
>>> sorted(max_dissimilarity_selection(X, 3))
[3, 4, 5]
libscientific.clustering.k_means_pp_centers(x_input: libscientific.matrix.MatrixLike, n_centers: int, nthreads: int | None = None) → list[int]

Choose well spread starting centers with the k-means++ seeding.

The first center is chosen at random; each following one is drawn with a probability proportional to its squared distance from the nearest center already chosen (D. Arthur and S. Vassilvitskii, 2007).

Parameters:

  • x_input (MatrixLike) – Data, shape (n_objects, n_features).

  • n_centers (int) – Number of centers.

  • nthreads (int, optional) – Number of threads (default: number of CPUs).

Returns:

Row indexes of the chosen objects. The choice is random: it can change between runs.

Return type:

list[int]

Examples

>>> X = [[0.0, 0.0], [0.1, 0.0], [5.0, 5.0], [5.1, 5.0], [0.0, 5.0], [10.0, 0.0]]
>>> centers = k_means_pp_centers(X, 3)
>>> len(centers), all(0 <= c < 6 for c in centers)
(3, True)
libscientific.clustering.k_means_plus_plus(x_input: libscientific.matrix.MatrixLike, n_clusters: int, nthreads: int | None = None) → list[int]

Cluster objects with k-means, initialized with k-means++.

Parameters:

  • x_input (MatrixLike) – Data, shape (n_objects, n_features).

  • n_clusters (int) – Number of clusters k.

  • nthreads (int, optional) – Number of threads (default: number of CPUs).

Returns:

Cluster label of every object, from 0 to k - 1. The initialization is random: the numbering of the clusters (and, for poorly separated data, the clusters themselves) can change between runs.

Return type:

list[int]

Examples

Two well separated groups always end up in two different clusters:

>>> X = [[0.0, 0.0], [0.1, 0.2], [0.2, 0.1], [9.0, 9.0], [9.1, 9.2], [9.2, 9.1]]
>>> labels = k_means_plus_plus(X, 2)
>>> len(labels), labels[0] == labels[1] == labels[2], labels[0] != labels[3]
(6, True, True)
