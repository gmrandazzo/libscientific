UPLS — Multi-way PLS

Multi-way (unfolded) Partial Least Squares regression (UPLS).

UPLS relates three-way predictors to (two- or three-way) responses. Both are given as lists of layers with the same objects:

X = [x_layer_0, ..., x_layer_{Kx-1}]   # each n_objects x n_features
Y = [y_layer_0, ..., y_layer_{Ky-1}]   # each n_objects x n_y

A single response matrix is a list with one layer: Y = [y]. Each latent variable has one X score per object and a weight/loading matrix n_features x Kx (Wold, Geladi and Esbensen, J. Chemometrics 1, 41-56, 1987).

>>> from libscientific.upls import UPLS
>>> X = [[[float(i + j + k) + 0.1 * ((i * 7 + j * 3 + k) % 5) for j in range(3)]
...       for i in range(12)] for k in range(2)]
>>> Y = [[[sum(X[k][i][j] for k in range(2) for j in range(3))] for i in range(12)]]
>>> model = UPLS(nlv=2)
>>> model.fit(X, Y)
>>> y_pred = model.predict(X)
>>> len(y_pred), len(y_pred[0]), len(y_pred[0][0])   # 1 Y layer, 12 objects, 1 response
(1, 12, 1)

The functions after the class are the low-level ctypes wrappers of upls.h.

class libscientific.upls.UPLS(nlv: int = 2, xscaling: int = 1, yscaling: int = 0)

Multi-way Partial Least Squares regression model.

Parameters:

  • nlv (int, default 2) – Number of latent variables; capped to n_features. After fit(), nlv holds the number actually computed.

  • xscaling (int, default 1 and 0) – Column preprocessing of every X and Y layer: all options mean-center each column, then 0 = no scaling, 1 = unit variance (autoscaling), 2 = root mean square, 3 = Pareto, 4 = range, 5 = level.

  • yscaling (int, default 1 and 0) – Column preprocessing of every X and Y layer: all options mean-center each column, then 0 = no scaling, 1 = unit variance (autoscaling), 2 = root mean square, 3 = Pareto, 4 = range, 5 = level.

nlv, xscaling, yscaling

See Parameters.

Type:

int

model

The underlying C model (low-level access, see UPLSMODEL).

Type:

ctypes.POINTER(UPLSMODEL)

Notes

  • The NIPALS iterations of UPLS stop at a relative change of 1e-3, a looser tolerance than PCA/PLS: results agree with other implementations to about 3 significant digits.

  • When Y is already fully explained, the remaining latent variables are skipped (a message is printed on standard error) and nlv is lowered accordingly.

  • For a single response, the inner coefficients b are 1: the regression coefficient is carried by the Y loadings.

fit(x_input: Any, y_input: Any) → None

Fit the model on three-way training data.

Calling fit again replaces the previous model.

Parameters:

  • x_input (list of matrices or 3D numpy array) – Kx X layers of shape (n_objects, n_features).

  • y_input (list of matrices or 3D numpy array) – Ky Y layers of shape (n_objects, n_y); [y] for a single response matrix.

Returns:

The model is updated in place.

Return type:

None

predict(x_input: Any, nlv_: int | None = None) → list[list[list[float]]]

Predict the responses of new objects.

Parameters:

  • x_input (list of matrices or 3D numpy array) – X layers of the new objects: same number of layers and features as the training data, any number of objects.

  • nlv_ (int, optional) – Number of latent variables to use (default: all).

Returns:

Ky predicted Y layers of shape (n_new_objects, n_y), in the original units of Y.

Return type:

list[list[list[float]]]

Raises:

ValueError – If nlv_ is not between 1 and nlv.

save(filepath: str) → None

Save the model to a file.

Parameters:

filepath (str) – Destination path. .sqlite3 or .db use the legacy SQLite format; any other extension (.lsm recommended) uses the binary libscientific model container.

Raises:

OSError – If the file cannot be written.

load(filepath: str) → None

Load a model saved with save(), replacing the current one.

After loading, nlv is set to the number of stored latent variables.

Parameters:

filepath (str) – Path of the model file; the format is detected automatically.

Raises:

OSError – If a binary model file cannot be read.

Low-level API

Thin ctypes wrappers around the C functions, working on raw C pointers. They are needed only to interoperate with other low-level code.

class libscientific.upls.UPLSMODEL

C structure holding a fitted UPLS model (low-level API).

Use UPLS instead of accessing this structure directly. With n objects, f features in Kx X layers, n_y responses in Ky Y layers and nlv latent variables:

xscores, yscores

X and Y scores, n x nlv.

Type:

POINTER(MATRIX)

xloadings, xweights

One f x Kx matrix per latent variable.

Type:

POINTER(TENSOR)

yloadings

One n_y x Ky matrix per latent variable.

Type:

POINTER(TENSOR)

b

Inner regression coefficient of each latent variable.

Type:

POINTER(DVECTOR)

xvarexp

Percentage of the X variance explained by each latent variable.

Type:

POINTER(DVECTOR)

xcolaverage, xcolscaling, ycolaverage, ycolscaling

Column means and scalings of each X and Y layer.

Type:

POINTER(DVECTLIST)

recalculated_y, recalc_residuals

Fitted Y of the training objects and residuals, one matrix per Y layer.

Type:

POINTER(TENSOR)

The validation fields (``q2y``, ``sdep``, ``predicted_y``, ...) are filled
by the cross-validation functions of the C library.
