Model files and bundles

Saving and loading models in the libscientific binary formats.

Two file formats, both without external dependencies:

  • .lsm: a single model;

  • .lsb: a bundle of named models (e.g. a PCA and a PLS of the same project) in one file.

Most of the time the save/load methods of the models are enough (PCA.save("model.lsm")). This module adds bundles and automatic detection of the file content:

>>> import os, tempfile
>>> from libscientific.pca import PCA
>>> from libscientific.pls import PLS
>>> from libscientific.model_io import ModelBundle, import_auto
>>> X = [[1.0, 2.0], [2.0, 1.0], [3.0, 4.0], [4.0, 3.0]]
>>> pca = PCA(npc=2); pca.fit(X)
>>> pls = PLS(nlv=2); pls.fit(X, [[1.0], [2.0], [3.0], [4.0]])
>>> path = os.path.join(tempfile.mkdtemp(), "project.lsb")
>>> ModelBundle({"pca": pca, "pls": pls}).save(path)
>>> bundle = import_auto(path)
>>> sorted(bundle.keys()), bundle["pca"].npc
(['pca', 'pls'], 2)
class libscientific.model_io.ModelType(value)

Type of a model stored in a model file.

Members: UNKNOWN (0), PCA (1), PLS (2), CPCA (3), MLR (4), LDA (5), ICA (6), UPCA (7), UPLS (8), ANY (255, accept any type when importing).

class libscientific.model_io.ModelBundle(models: dict[str, Any] | list[Any] | tuple[Any, ...] | None = None)

A dictionary-like collection of named models, saved to one .lsb file.

Parameters:

models (dict[str, model], list of models or None) – Initial models. A list gets the names model_0, model_1, …

Notes

Supports bundle[name], bundle[name] = model, del bundle[name], name in bundle, len(bundle), iteration over the names, keys(), values() and items().

Examples

>>> from libscientific.pca import PCA
>>> pca = PCA(npc=1); pca.fit([[1.0, 2.0], [2.0, 1.0], [3.0, 4.0]])
>>> bundle = ModelBundle({"pca": pca})
>>> len(bundle), "pca" in bundle
(1, True)

Low-level API

Thin ctypes wrappers around the C functions, working on raw C pointers. They are needed only to interoperate with other low-level code.

class libscientific.model_io.MODEL_FILE_INFO

C structure filled by InspectModelFile (low-level API, see inspect_model_file()).

class libscientific.model_io.MODEL_ENTRY

C structure of one named model inside a bundle (low-level API).

class libscientific.model_io.MODEL_BUNDLE

C structure of a model bundle (low-level API, see ModelBundle).
