Vectors

Vectors stored in the C library.

  • DVector (double values) and UIVector (unsigned integers): Pythonic vectors.

  • Low-level functions for double (dvector), unsigned int (uivector) and int (ivector) C vectors.

    >>> from libscientific.vector import DVector
>>> v = DVector([1.0, 2.0, 3.0])
>>> len(v), v[-1]
(3, 3.0)
class libscientific.vector.DVector(dvect_=None)

A double vector stored in the C library, with a Pythonic interface.

Parameters:

dvect (list[float], DVector or None) – Initial values (copied), or None for an empty vector.

dvect

The underlying C vector, owned by this object.

Type:

ctypes.POINTER(DVECTOR)

Notes

v[i] reads/writes one element (negative indexes count from the end and out-of-range indexes raise IndexError), len(v) is the size and iterating yields the values.

Examples

>>> v = DVector([1.0, 2.0, 3.0])
>>> v.append(4.0)
>>> len(v), v[-1]
(4, 4.0)
>>> v.tolist()
[1.0, 2.0, 3.0, 4.0]

libscientific.vector.dvector_has_value(dvect, val)

Check whether a C double vector contains a value.

Parameters:

  • dvect (ctypes.POINTER(DVECTOR)) – The vector to search.

  • val (float) – The value to look for (compared within the library tolerance EPSILON).

Returns:

0 if the value is present, 1 if it is not (C library convention).

Return type:

int

Examples

>>> v = new_dvector([1.0, 2.0])
>>> dvector_has_value(v, 2.0), dvector_has_value(v, 5.0)
(0, 1)

Low-level API
