UPCA — Multi-way PCA

Multi-way (unfolded) Principal Component Analysis (UPCA).

UPCA analyses three-way data: n_objects objects, each described by n_features variables measured in n_layers conditions (e.g. time points, wavelengths, batches). The data are given as a list of layers:

X = [layer_0, layer_1, ..., layer_{K-1}]      # each n_objects x n_features

and every layer must have the same shape. Each component has one score per object and a loading matrix n_features x n_layers constrained to be the outer product of a feature profile and a layer profile (Wold, Geladi and Esbensen, Multi-way principal components and PLS analysis, J. Chemometrics 1, 41-56, 1987).

>>> import math
>>> from libscientific.upca import UPCA
>>> X = [[[3.0 * (j + 1) + math.sin(0.9 * (i + 1)) * (1 + 0.5 * j) * (1 + 0.7 * k)
...        for j in range(4)] for i in range(15)] for k in range(3)]
>>> model = UPCA(npc=1, scaling=1)
>>> model.fit(X)                      # 3 layers of 15 objects x 4 features
>>> [round(v, 4) for v in model.get_exp_variance()]
[100.0]

The functions after the class are the low-level ctypes wrappers of upca.h.

class libscientific.upca.UPCA(npc: int = 2, scaling: int = 1)

Multi-way Principal Component Analysis model.

Parameters:

  • npc (int, default 2) – Number of components; capped to n_features. After fit(), npc holds the number of components actually computed.

  • scaling (int, default 1) – Column preprocessing applied to every layer: all options mean-center each column, then 0 = no scaling, 1 = unit variance (autoscaling), 2 = root mean square, 3 = Pareto, 4 = range, 5 = level.

npc, scaling

See Parameters.

Type:

int

model

The underlying C model (low-level access, see UPCAMODEL).

Type:

ctypes.POINTER(UPCAMODEL)

Notes

Because the loading matrix of each component is constrained to rank 1, the components are computed one after another and are not exactly orthogonal: with several components the explained variances can add up to slightly more than 100%, and the reconstruction of general data is approximate. Data that follow the model exactly (a sum of score x feature profile x layer profile terms with orthogonal profiles) are reconstructed exactly.

predict(x_input: Any) → list[list[float]]

Project new objects into the model.

Parameters:

x_input (list of matrices or 3D numpy array) – Same number of layers and features as the training data, any number of objects.

Returns:

Scores of the new objects, shape (n_new_objects, npc). Projecting the training data gives get_scores().

Return type:

list[list[float]]

Examples

>>> import math
>>> X = [[[3.0 * (j + 1) + math.sin(0.9 * (i + 1)) * (1 + 0.5 * j) * (1 + 0.7 * k)
...        for j in range(4)] for i in range(15)] for k in range(3)]
>>> model = UPCA(npc=1)
>>> model.fit(X)
>>> scores = model.predict([layer[:2] for layer in X])   # first 2 objects
>>> [round(a - b, 6) for a, b in zip(scores[0], model.get_scores()[0])]
[0.0]
reconstruct_original_tensor(npc_input: int | None = None, scores_input: Any | None = None) → list[list[list[float]]]

Rebuild three-way data in the original units from scores.

Parameters:

  • npc_input (int, optional) – Number of components to use (default: all).

  • scores_input (MatrixLike, optional) – Scores, shape (n_objects, npc), e.g. from predict(). Default: the training scores.

Returns:

n_layers matrices of shape (n_objects, n_features).

Return type:

list[list[list[float]]]

Examples

Data that follow a one-component model are rebuilt exactly:

>>> import math
>>> X = [[[3.0 * (j + 1) + math.sin(0.9 * (i + 1)) * (1 + 0.5 * j) * (1 + 0.7 * k)
...        for j in range(4)] for i in range(15)] for k in range(3)]
>>> model = UPCA(npc=1, scaling=1)
>>> model.fit(X)
>>> Xr = model.reconstruct_original_tensor()
>>> max(abs(Xr[k][i][j] - X[k][i][j])
...     for k in range(3) for i in range(15) for j in range(4)) < 1e-9
True

Save the model to a file.

Parameters:

filepath (str) – Destination path. .sqlite3 or .db use the legacy SQLite format; any other extension (.lsm recommended) uses the binary libscientific model container.

Raises:

OSError – If the file cannot be written.

load(filepath: str) → None

Load a model saved with save(), replacing the current one.

After loading, npc is set to the number of stored components.

Parameters:

filepath (str) – Path of the model file; the format is detected automatically.

Raises:

OSError – If a binary model file cannot be read.

Low-level API

Thin ctypes wrappers around the C functions, working on raw C pointers. They are needed only to interoperate with other low-level code.
