MLR — Multiple Linear Regression

Multiple Linear Regression (MLR) by ordinary least squares.

MLR fits, for every response y_k, the linear equation:

y_k = b_0k + b_1k * x_1 + b_2k * x_2 + ... + b_fk * x_f

where b_0k is the intercept. Each response is fitted independently.

>>> from libscientific.mlr import MLR
>>> X = [[1.0, 0.0], [2.0, 1.0], [3.0, 4.0], [4.0, 2.0], [5.0, 3.0]]
>>> y = [[1.0 + 2.0 * a - 0.5 * b] for a, b in X]
>>> model = MLR()
>>> model.fit(X, y)
>>> [round(row[0], 6) for row in model.get_coefficients()]   # intercept, x1, x2
[1.0, 2.0, -0.5]
>>> round(model.predict([[10.0, 2.0]])[0][0], 6)
20.0

The functions after the class are the low-level ctypes wrappers of mlr.h.

class libscientific.mlr.MLR

Multiple Linear Regression model (ordinary least squares).

model

The underlying C model (low-level access, see MLRMODEL).

Type:

ctypes.POINTER(MLRMODEL)

Notes

  • Y is always 2D: one column per response ([[y1], [y2], ...] for a single response). Every response gets its own coefficients.

  • The data are not scaled: coefficients are in the units of the data.

  • OLS needs more objects than features, and features that are not linear combinations of each other; otherwise prefer PLS.

Examples

Two responses at once:

>>> X = [[1.0, 0.0], [2.0, 1.0], [3.0, 4.0], [4.0, 2.0], [5.0, 3.0]]
>>> Y = [[1.0 + 2.0 * a - 0.5 * b, 3.0 - a + b] for a, b in X]
>>> model = MLR()
>>> model.fit(X, Y)
>>> [[round(v, 6) for v in row] for row in model.get_coefficients()]
[[1.0, 3.0], [2.0, -1.0], [-0.5, 1.0]]
>>> [round(v, 6) for v in model.get_r2()]       # perfect fit
[1.0, 1.0]
fit(x_input: libscientific.matrix.MatrixLike, y_input: libscientific.matrix.MatrixLike) → None

Fit the coefficients by ordinary least squares.

Calling fit again replaces the previous model.

Parameters:

  • x_input (MatrixLike) – Predictors, shape (n_objects, n_features).

  • y_input (MatrixLike) – Responses, shape (n_objects, n_y).

Returns:

The model is updated in place.

Return type:

None

get_coefficients() → list[list[float]]

Return the regression coefficients.

Returns:

Matrix of shape (n_features + 1, n_y): row 0 holds the intercepts, row j + 1 the coefficients of feature j; column k refers to response k.

Return type:

list[list[float]]

get_recalculated_y() → list[list[float]]

Return the fitted responses of the training objects.

Returns:

Matrix of shape (n_objects, n_y).

Return type:

list[list[float]]

get_residuals() → list[list[float]]

Return the training residuals (fitted minus true response).

Returns:

Matrix of shape (n_objects, n_y).

Return type:

list[list[float]]

get_r2() → list[float]

Return the coefficient of determination R² of the training fit.

Returns:

One value per response: 1 - SS(residuals) / SS(y - mean(y)).

Return type:

list[float]

get_sdec() → list[float]

Return the standard deviation of the training errors (SDEC).

Returns:

One value per response: sqrt(SS(residuals) / n_objects), in the units of the response.

Return type:

list[float]

predict(x_input: libscientific.matrix.MatrixLike) → list[list[float]]

Predict the responses of new objects.

Parameters:

x_input (MatrixLike) – Objects, shape (n_new_objects, n_features), with the same features (same order) as the training data.

Returns:

Predicted responses, shape (n_new_objects, n_y).

Return type:

list[list[float]]

Raises:

ValueError – If the number of features differs from the training data.

Examples

>>> model = MLR()
>>> model.fit([[0.0], [1.0], [2.0]], [[1.0], [3.0], [5.0]])   # y = 1 + 2x
>>> [[round(v, 6) for v in row] for row in model.predict([[10.0], [-1.0]])]
[[21.0], [-1.0]]
save(filepath: str) → None

Save the model to a file.

Parameters:

filepath (str) – Destination path. .sqlite3 or .db use the legacy SQLite format; any other extension (.lsm recommended) uses the binary libscientific model container.

Raises:

OSError – If the file cannot be written.

load(filepath: str) → None

Load a model saved with save(), replacing the current one.

Parameters:

filepath (str) – Path of the model file; the format is detected automatically.

Raises:

OSError – If a binary model file cannot be read.

Examples

>>> import os, tempfile
>>> model = MLR()
>>> model.fit([[0.0], [1.0], [2.0]], [[1.0], [3.0], [5.0]])
>>> path = os.path.join(tempfile.mkdtemp(), "mlr.lsm")
>>> model.save(path)
>>> loaded = MLR()
>>> loaded.load(path)
>>> loaded.predict([[4.0]]) == model.predict([[4.0]])
True

Low-level API

Thin ctypes wrappers around the C functions, working on raw C pointers. They are needed only to interoperate with other low-level code.

class libscientific.mlr.MLRMODEL

C structure holding a fitted MLR model (low-level API).

Use MLR instead of accessing this structure directly. With n objects, f features and n_y responses:

b

Coefficients, (f + 1) x n_y: row 0 is the intercept, row j + 1 the coefficient of feature j.

Type:

POINTER(MATRIX)

recalculated_y, recalc_residuals

Fitted responses of the training objects and residuals (fitted - true), n x n_y.

Type:

POINTER(MATRIX)

ymean

Mean of each training response.

Type:

POINTER(DVECTOR)

r2y_model, sdec

R² and standard deviation of the errors of the training fit, one value per response.

Type:

POINTER(DVECTOR)

predicted_y, pred_residuals, q2y, sdep, bias, r2q2scrambling

Filled by the validation functions of the C library (cross-validation, y-scrambling); empty after a plain fit.
