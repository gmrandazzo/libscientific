Interpolation

Natural cubic spline interpolation.

>>> from libscientific.interpolate import CubicSplineInterpolation
>>> spline = CubicSplineInterpolation()
>>> spline.fit([[0.0, 0.0], [1.0, 1.0], [2.0, 4.0], [3.0, 9.0]])
>>> round(spline.predict([2.0])[0], 6)
4.0
class libscientific.interpolate.CubicSplineInterpolation

Natural cubic spline interpolation of 2D points.

The spline goes exactly through every given point, with continuous first and second derivatives, and zero second derivative at the two ends.

s_interp

The spline coefficients (see cubic_spline_interpolation()), None before fit().

Type:

ctypes.POINTER(MATRIX) or None

Examples

>>> import math
>>> from libscientific.interpolate import CubicSplineInterpolation
>>> points = [[x / 2, math.sin(x / 2)] for x in range(13)]   # x from 0 to 6
>>> spline = CubicSplineInterpolation()
>>> spline.fit(points)
>>> [round(y, 3) for y in spline.predict([0.25, 1.1, 3.3])]
[0.247, 0.891, -0.158]
fit(x_y_) → None

Compute the spline through a set of points.

Calling fit again replaces the previous spline.

Parameters:

x_y (MatrixLike) – The points, shape (n_points, 2): [[x0, y0], [x1, y1], ...]. Lists and numpy arrays are sorted by x automatically; a Matrix must already be sorted. The x values must be distinct.

Return type:

None

predict(x_pred_)

Evaluate the spline at new x values.

Parameters:

x_pred (list[float], DVector or ctypes.POINTER(DVECTOR)) – The x values. Values outside the range of the fitted points are extrapolated with the first/last polynomial and are not reliable.

Returns:

One y value per x.

Return type:

list[float]

Raises:

RuntimeError – If the spline has not been fitted.

Low-level API

Thin ctypes wrappers around the C functions, working on raw C pointers. They are needed only to interoperate with other low-level code.

libscientific.interpolate.cubic_spline_interpolation(x_y, s_interp)

Compute the coefficients of a natural cubic spline (low-level API).

Parameters:

  • x_y (Matrix or ctypes.POINTER(MATRIX)) – The points, shape (n_points, 2): column 0 is x (sorted in increasing order, no duplicates), column 1 is y.

  • s_interp (Matrix or ctypes.POINTER(MATRIX)) – Output matrix; receives one row per interval, (n_points - 1, 5): [x_i, a, b, c, d] with y = a + b (x - x_i) + c (x - x_i)^2 + d (x - x_i)^3 on [x_i, x_{i+1}].

libscientific.interpolate.cubic_spline_predict(x_cc, s_interp, y_pred)

Evaluate a natural cubic spline (low-level API).

Parameters:

  • x_cc (DVector or ctypes.POINTER(DVECTOR)) – The x values to evaluate.

  • s_interp (Matrix or ctypes.POINTER(MATRIX)) – Spline coefficients from cubic_spline_interpolation().

  • y_pred (DVector or ctypes.POINTER(DVECTOR)) – Output vector; resized and filled with one y value per x.
