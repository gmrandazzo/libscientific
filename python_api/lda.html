LDA — Linear Discriminant Analysis

Linear Discriminant Analysis (Fisher LDA) for classification.

LDA finds the directions that best separate the classes (maximum ratio of between-class to within-class scatter) and classifies an object into the class with the highest linear discriminant score:

score_k(x) = mu_k' S^-1 x - 1/2 mu_k' S^-1 mu_k + ln(prior_k)

where mu_k is the mean of class k, S the pooled within-class covariance and prior_k the fraction of training objects in class k.

Class labels are integers numbered from 0 (0..K-1) or from 1 (1..K), without gaps; predictions use the same numbering.

>>> from libscientific.lda import LDA
>>> X = [[1.0, 1.0], [1.5, 2.0], [2.0, 1.5], [6.0, 5.0], [6.5, 6.0], [7.0, 5.5]]
>>> y = [1, 1, 1, 2, 2, 2]
>>> model = LDA()
>>> model.fit(X, y)
>>> model.predict([[1.2, 1.4], [6.8, 5.9]])
[1, 2]

The functions after the class are the low-level ctypes wrappers of lda.h.

class libscientific.lda.LDA

Linear Discriminant Analysis classifier.

model

The underlying C model (low-level access, see LDAMODEL).

Type:

ctypes.POINTER(LDAMODEL)

Notes

  • Labels must be integers 0..K-1 or 1..K with every class present; predictions use the same numbering.

  • When the within-class scatter matrix is singular (e.g. more features than objects), its pseudo-inverse is used (Liu et al., Int. J. Patt. Recogn. Artif. Intell. 21, 1265, 2007).

Examples

>>> X = [[1.0, 1.0], [1.5, 2.0], [2.0, 1.5], [6.0, 5.0], [6.5, 6.0], [7.0, 5.5],
...      [1.0, 6.0], [1.5, 7.0], [2.0, 6.5]]
>>> y = [0, 0, 0, 1, 1, 1, 2, 2, 2]
>>> model = LDA()
>>> model.fit(X, y)
>>> model.nclass, model.classes
(3, [0, 1, 2])
>>> model.predict(X) == y
True
>>> [round(p, 4) for p in model.get_priors()]
[0.3333, 0.3333, 0.3333]
property nclass: int

Number of classes of the fitted model.

property classes: list[int]

Class labels of the fitted model, e.g. [0, 1, 2] or [1, 2, 3].

fit(x_input: MatrixLike, y_input: Sequence[int] | MatrixLike) → None

Fit the discriminant model.

Calling fit again replaces the previous model.

Parameters:

  • x_input (MatrixLike) – Training objects, shape (n_objects, n_features).

  • y_input (list[int] or MatrixLike) – Class label of each object: a flat list ([0, 1, 1, ...]) or a one-column matrix ([[0], [1], [1], ...]).

Returns:

The model is updated in place.

Return type:

None

predict(x_input: libscientific.matrix.MatrixLike) → list[int]

Predict the class of new objects.

Parameters:

x_input (MatrixLike) – Objects, shape (n_new_objects, n_features).

Returns:

One label per object, in the numbering of the training labels.

Return type:

list[int]

Examples

>>> model = LDA()
>>> model.fit([[1.0, 1.0], [1.5, 2.0], [2.0, 1.5], [6.0, 5.0], [6.5, 6.0], [7.0, 5.5]],
...           [1, 1, 1, 2, 2, 2])
>>> model.predict([[0.5, 0.8], [8.0, 7.0]])
[1, 2]
predict_scores(x_input: libscientific.matrix.MatrixLike) → list[list[float]]

Return the linear discriminant score of each object for each class.

The predicted class is the one with the highest score. Scores are log-scale values, not probabilities: only their differences matter.

Parameters:

x_input (MatrixLike) – Objects, shape (n_new_objects, n_features).

Returns:

Matrix of shape (n_new_objects, nclass); column k refers to label classes[k].

Return type:

list[list[float]]

transform(x_input: libscientific.matrix.MatrixLike) → list[list[float]]

Project objects on the discriminant directions.

Useful to plot the classes: the first columns (largest eigenvalues) separate them best.

Parameters:

x_input (MatrixLike) – Objects, shape (n_new_objects, n_features).

Returns:

Matrix of shape (n_new_objects, n_features): column l is the projection on eigenvector l (see get_eigenvectors()).

Return type:

list[list[float]]

get_eigenvalues() → list[float]

Return the eigenvalues of the discriminant directions.

Returns:

One value per direction (n_features values); larger values mean better class separation. At most nclass - 1 are significantly different from zero.

Return type:

list[float]

get_eigenvectors() → list[list[float]]

Return the discriminant directions.

Returns:

Matrix of shape (n_features, n_features): column l is the direction associated with eigenvalue l.

Return type:

list[list[float]]

get_class_means() → list[list[float]]

Return the mean of each class in the original feature space.

Returns:

Matrix of shape (nclass, n_features); row k refers to label classes[k].

Return type:

list[list[float]]

get_priors() → list[float]

Return the prior probability of each class.

Returns:

nclass values: the fraction of training objects in each class.

Return type:

list[float]

save(filepath: str) → None

Save the model to a file.

Parameters:

filepath (str) – Destination path. .sqlite3 or .db use the legacy SQLite format; any other extension (.lsm recommended) uses the binary libscientific model container.

Raises:

OSError – If the file cannot be written.

load(filepath: str) → None

Load a model saved with save(), replacing the current one.

Parameters:

filepath (str) – Path of the model file; the format is detected automatically.

Raises:

OSError – If a binary model file cannot be read.

Examples

>>> import os, tempfile
>>> X = [[1.0, 1.0], [1.5, 2.0], [2.0, 1.5], [6.0, 5.0], [6.5, 6.0], [7.0, 5.5]]
>>> model = LDA()
>>> model.fit(X, [0, 0, 0, 1, 1, 1])
>>> path = os.path.join(tempfile.mkdtemp(), "lda.lsm")
>>> model.save(path)
>>> loaded = LDA()
>>> loaded.load(path)
>>> loaded.predict(X)
[0, 0, 0, 1, 1, 1]

Low-level API

Thin ctypes wrappers around the C functions, working on raw C pointers. They are needed only to interoperate with other low-level code.

class libscientific.lda.LDAMODEL

C structure holding a fitted LDA model (low-level API).

Use LDA instead of accessing this structure directly. With n objects, f features and K classes:

inv_cov

Inverse (or pseudo-inverse) of the pooled within-class scatter, f x f.

Type:

POINTER(MATRIX)

evect, eval

Discriminant directions (f x f, one per column) and their eigenvalues (size f).

Type:

POINTER(MATRIX), POINTER(DVECTOR)

mu

Class means, K x f.

Type:

POINTER(MATRIX)

pprob

Prior probability of each class (fraction of training objects).

Type:

POINTER(DVECTOR)

features, mnpdf

Training objects projected on the discriminant directions, and their normal densities: one n_k x f matrix per class.

Type:

POINTER(TENSOR)

fmean, fsdev

Mean and standard deviation of the projected features per class, K x f.

Type:

POINTER(MATRIX)

classid

Row indexes of the training objects, grouped by class.

Type:

POINTER(UIVECTOR)

nclass, class_start

Number of classes and first label (0 or 1).

Type:

int
