Library loading

Locate and load the libscientific C library.

Used internally at import time: the library bundled in the wheel is loaded first; otherwise it is searched in LD_LIBRARY_PATH / DYLD_LIBRARY_PATH and the system library directories.

Functions

libscientific.loadlibrary.get_platform_info() → tuple[str, str]

Return the operating system and the CPU architecture.

Returns:

(system, machine) in lower case, e.g. ("linux", "x86_64") or ("darwin", "arm64"); amd64 is reported as x86_64 and aarch64 as arm64.

Return type:

tuple[str, str]

libscientific.loadlibrary.get_platform_specific_paths() → list[Path]

Return the standard library directories of the current platform.

Returns:

Directories such as /usr/lib, /usr/local/lib, Homebrew prefixes on macOS, …

Return type:

list[pathlib.Path]

libscientific.loadlibrary.get_search_paths(local_path: Path, verbose: bool = False) → list[Path]

Return all the directories where the libraries are searched.

Parameters:

  • local_path (pathlib.Path) – The package directory (searched first, together with its lib subdirectory).

  • verbose (bool, default False) – Print the directories.

Returns:

Existing directories: the package directory, the directories in LD_LIBRARY_PATH, LIBRARY_PATH, DYLD_LIBRARY_PATH and the platform directories.

Return type:

list[pathlib.Path]

libscientific.loadlibrary.get_lib_extensions() → list[str]

Return the shared library file extensions of the current platform.

Returns:

[".so", ".so.*"] on Linux, [".dylib", ".dylib.*"] on macOS, [".dll"] on Windows (all of them on other systems).

Return type:

list[str]

libscientific.loadlibrary.find_versioned_library(base_path: Path, lib_name: str) → Path | None

Find a versioned shared library in a directory (e.g. libfoo.so.3).

Parameters:

  • base_path (pathlib.Path) – Directory to search.

  • lib_name (str) – Library file name without version, e.g. "libgfortran.so".

Returns:

The matching file with the highest version, or None.

Return type:

pathlib.Path or None

libscientific.loadlibrary.find_library(lib_name: str, local_path: Path, verbose: bool = False) → Path | None

Find a shared library in the package directory and the system paths.

Parameters:

  • lib_name (str) – File name, e.g. "liblapack.so" (.so is replaced by .dylib on macOS). Versioned files (liblapack.so.3) are also accepted.

  • local_path (pathlib.Path) – The package directory, searched first.

  • verbose (bool, default False) – Print every path checked.

Returns:

Path of the library, or None if it is not found.

Return type:

pathlib.Path or None

Examples

>>> import pathlib
>>> find_library("liblapack.so", pathlib.Path("/usr/lib"))  
PosixPath('/usr/lib/x86_64-linux-gnu/liblapack.so.3')

libscientific.loadlibrary.load_library_for_posix()

Load libscientific on Linux and macOS.

The library bundled in the wheel is loaded first (its dependencies are bundled too). Otherwise the dependencies (gfortran, quadmath, BLAS, LAPACK) are preloaded and libscientific.so/.dylib is searched in the system paths (see get_search_paths()).

Returns:

The loaded library.

Return type:

ctypes.CDLL

Raises:

RuntimeError – If the library or one of its dependencies cannot be found or loaded; the message explains how to install it or set LD_LIBRARY_PATH / DYLD_LIBRARY_PATH.

libscientific.loadlibrary.load_library_for_nt()

Load libscientific.dll from the package directory (Windows).

The runtime DLLs it needs (LAPACK, BLAS, gfortran, …) are bundled in the same directory.

Returns:

The loaded library, or None if it cannot be loaded.

Return type:

ctypes.WinDLL or None

libscientific.loadlibrary.load_libscientific_library()

Load the libscientific C library for the current platform.

Every module of the package calls this function at import time; the result is the ctypes handle used to call the C functions.

Returns:

The loaded library.

Return type:

ctypes.CDLL

Raises:

RuntimeError – If the library cannot be loaded (POSIX systems).
