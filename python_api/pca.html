PCA — Principal Component Analysis

Principal Component Analysis (PCA).

PCA decomposes a data matrix X (n_objects rows x n_features columns) into npc principal components:

X_preprocessed = T @ P.T + E

where T are the scores (n_objects x npc, the coordinates of each object in the new space), P are the loadings (n_features x npc, the weight of each feature in each component) and E is the residual. Components are computed one at a time with the NIPALS algorithm, so only the requested components are calculated.

Most users only need the PCA class:

>>> from libscientific.pca import PCA
>>> X = [[1.0, 2.0, 3.0], [2.0, 1.0, 4.0], [3.0, 4.0, 2.0],
...      [4.0, 3.0, 1.0], [5.0, 5.0, 0.5]]
>>> model = PCA(scaling=1, npc=2)
>>> model.fit(X)
>>> [round(v, 2) for v in model.get_exp_variance()]
[90.4, 6.67]

The functions below the class (new_pca_model, pca_algorithm, …) are the low-level ctypes wrappers of the C API; they work with raw C pointers and are only needed to interoperate with other low-level code.

class libscientific.pca.PCA(scaling: int = 1, npc: int = 2)

Principal Component Analysis model (NIPALS algorithm).

Parameters:

  • scaling (int, default 1) –

    Column preprocessing applied before the decomposition. Every option mean-centers the columns; the options differ in how they are scaled:

    0

    mean centering only (no scaling)

    1

    unit variance / autoscaling (divide by the standard deviation)

    2

    root mean square of the column

    3

    Pareto (divide by the square root of the standard deviation)

    4

    range (divide by max - min)

    5

    level (divide by the column mean)

    Use 1 when the features have different units or ranges, 0 when they are already on the same scale.

  • npc (int, default 2) – Number of principal components to compute. It is capped to the number of features: after fit(), npc holds the number of components actually computed.

scaling

The preprocessing option given at construction.

Type:

int

npc

Number of principal components of the model.

Type:

int

model

The underlying C model (low-level access, see PCAMODEL).

Type:

ctypes.POINTER(PCAMODEL)

Notes

  • The sign of each component is arbitrary: scores and loadings of a component can be multiplied by -1 between runs or platforms without changing the model.

  • Missing values can be passed as float('nan') (or as the value returned by libscientific.misc.missing_value()): they are skipped during the decomposition.

  • Inputs can be lists of rows, numpy arrays or Matrix objects (see MatrixLike). Results are returned as Python lists; wrap them with numpy.array(...) if needed.

Examples

>>> from libscientific.pca import PCA
>>> X = [[1.0, 2.0, 3.0], [2.0, 1.0, 4.0], [3.0, 4.0, 2.0],
...      [4.0, 3.0, 1.0], [5.0, 5.0, 0.5]]
>>> model = PCA(scaling=1, npc=2)
>>> model.fit(X)
>>> scores = model.get_scores()        # 5 objects x 2 components
>>> len(scores), len(scores[0])
(5, 2)
>>> loadings = model.get_loadings()    # 3 features x 2 components
>>> len(loadings), len(loadings[0])
(3, 2)
>>> [round(v, 2) for v in model.get_exp_variance()]   # % per component
[90.4, 6.67]
>>> new_scores = model.predict([[2.5, 2.5, 2.5]])     # project new objects
>>> len(new_scores), len(new_scores[0])
(1, 2)

Save the model and load it back:

>>> import os, tempfile
>>> path = os.path.join(tempfile.mkdtemp(), "model.lsm")
>>> model.save(path)
>>> model2 = PCA()
>>> model2.load(path)
>>> model2.npc
2
fit(m_input: libscientific.matrix.MatrixLike) → None

Compute the principal components of a matrix.

The columns are preprocessed according to scaling, then npc components are extracted. Results are stored in the model and read with get_scores(), get_loadings(), get_exp_variance() and get_dmodx(). Calling fit again replaces the previous model.

Parameters:

m_input (MatrixLike) – Training data, shape (n_objects, n_features): one row per object, one column per feature.

Returns:

The model is updated in place.

Return type:

None

Examples

>>> model = PCA(scaling=1, npc=5)
>>> model.fit([[1.0, 2.0, 3.0], [2.0, 1.0, 4.0], [3.0, 4.0, 2.0]])
>>> model.npc       # capped to the number of features
3
get_scores() → list[list[float]]

Return the scores of the training objects.

The scores are the coordinates of each training object in the space of the principal components.

Returns:

Matrix of shape (n_objects, npc): row i holds the coordinates of training object i, column k refers to component k.

Return type:

list[list[float]]

See also

predict

scores of new objects.

Examples

>>> model = PCA(npc=2)
>>> model.fit([[1.0, 2.0, 3.0], [2.0, 1.0, 4.0], [3.0, 4.0, 2.0], [4.0, 3.0, 1.0]])
>>> scores = model.get_scores()
>>> len(scores), len(scores[0])
(4, 2)
get_loadings() → list[list[float]]

Return the loadings of the features.

The loadings describe how much each original feature contributes to each principal component. Each column is a unit-length vector.

Returns:

Matrix of shape (n_features, npc): row j refers to feature j, column k to component k.

Return type:

list[list[float]]

Examples

>>> model = PCA(npc=2)
>>> model.fit([[1.0, 2.0, 3.0], [2.0, 1.0, 4.0], [3.0, 4.0, 2.0], [4.0, 3.0, 1.0]])
>>> loadings = model.get_loadings()
>>> len(loadings), len(loadings[0])
(3, 2)
>>> round(sum(row[0] ** 2 for row in loadings), 6)   # unit-length columns
1.0
get_exp_variance() → list[float]

Return the variance explained by each component, in percent.

Values are per component (not cumulative) and relative to the total variance of the preprocessed training matrix, so their sum is at most 100.

Returns:

npc values; element k is the percentage of variance explained by component k.

Return type:

list[float]

Examples

>>> model = PCA(scaling=1, npc=3)
>>> model.fit([[1.0, 2.0, 3.0], [2.0, 1.0, 4.0], [3.0, 4.0, 2.0],
...            [4.0, 3.0, 1.0], [5.0, 5.0, 0.5]])
>>> [round(v, 2) for v in model.get_exp_variance()]
[90.4, 6.67, 2.94]
>>> round(sum(model.get_exp_variance()), 6)   # all components: 100%
100.0
get_dmodx() → list[list[float]]

Return the distance of each training object to the model (DModX).

DModX is the norm of the residual of an object, i.e. the part of the object that is not explained by the components. Large values point to objects that the model does not describe well (possible outliers).

Returns:

Matrix of shape (n_objects, npc): element [i][k] is the distance of object i after removing components 0..k, so each row decreases from left to right.

Return type:

list[list[float]]

Examples

>>> model = PCA(npc=2)
>>> model.fit([[1.0, 2.0, 3.0], [2.0, 1.0, 4.0], [3.0, 4.0, 2.0], [4.0, 3.0, 1.0]])
>>> dmodx = model.get_dmodx()
>>> len(dmodx), len(dmodx[0])
(4, 2)
>>> all(row[0] >= row[1] for row in dmodx)
True
predict(m_input: libscientific.matrix.MatrixLike) → list[list[float]]

Project new objects into the model and return their scores.

The new data are preprocessed with the column means and scalings of the training data, then projected onto the loadings. Projecting the training matrix itself gives the same values as get_scores().

Parameters:

m_input (MatrixLike) – Objects to project, shape (n_new_objects, n_features). The columns must be the same features, in the same order, as the training data.

Returns:

Predicted scores, shape (n_new_objects, npc).

Return type:

list[list[float]]

See also

reconstruct_original_matrix

go back from scores to the original features.

Examples

>>> X = [[1.0, 2.0, 3.0], [2.0, 1.0, 4.0], [3.0, 4.0, 2.0], [4.0, 3.0, 1.0]]
>>> model = PCA(npc=2)
>>> model.fit(X)
>>> new_scores = model.predict([[2.5, 2.5, 2.5], [1.0, 1.0, 1.0]])
>>> len(new_scores), len(new_scores[0])
(2, 2)
reconstruct_original_matrix(npc_input: int | None = None, scores_input: MatrixLike | None = None) → list[list[float]]

Rebuild data in the original feature space from scores.

Computes T @ P.T with the first npc_input components, then reverts the scaling and centering, so the result is in the same units as the training data. With all the components the training matrix is reconstructed exactly; with fewer components the result is a denoised approximation.

Parameters:

  • npc_input (int, optional) – Number of components to use, from 1 to npc. Default: all the components of the model.

  • scores_input (MatrixLike, optional) – Scores to transform back, shape (n_objects, npc), e.g. the output of predict(). Default: the scores of the training data.

Returns:

Reconstructed data, shape (n_objects, n_features).

Return type:

list[list[float]]

Examples

>>> X = [[1.0, 2.0, 3.0], [2.0, 1.0, 4.0], [3.0, 4.0, 2.0], [4.0, 3.0, 1.0]]
>>> model = PCA(npc=3)
>>> model.fit(X)
>>> Xr = model.reconstruct_original_matrix()            # all components
>>> [round(v, 6) for v in Xr[0]]
[1.0, 2.0, 3.0]
>>> Xr2 = model.reconstruct_original_matrix(npc_input=1)  # approximation
>>> len(Xr2), len(Xr2[0])
(4, 3)

Reconstruct new objects from their predicted scores:

>>> s = model.predict([[2.5, 2.5, 2.5]])
>>> [round(v, 6) for v in model.reconstruct_original_matrix(scores_input=s)[0]]
[2.5, 2.5, 2.5]
save(filepath: str) → None

Save the model to a file.

Parameters:

filepath (str) – Destination path. The format is chosen from the extension: .sqlite3 or .db use the legacy SQLite format; any other extension (.lsm recommended) uses the binary libscientific model container, which is faster and needs no extra dependency.

Raises:

OSError – If the file cannot be written.

Examples

>>> import os, tempfile
>>> model = PCA(npc=2)
>>> model.fit([[1.0, 2.0, 3.0], [2.0, 1.0, 4.0], [3.0, 4.0, 2.0], [4.0, 3.0, 1.0]])
>>> model.save(os.path.join(tempfile.mkdtemp(), "pca.lsm"))
load(filepath: str) → None

Load a model saved with save(), replacing the current one.

The format is detected from the file content (binary container) or the extension (.lsm/.lsb; anything else is read as SQLite). After loading, npc is set to the number of components stored in the file. scaling is not stored and is left unchanged; it is not needed for predict(), which uses the saved column averages and scalings.

Parameters:

filepath (str) – Path of the model file.

Raises:

OSError – If a binary model file cannot be read.

Examples

>>> import os, tempfile
>>> path = os.path.join(tempfile.mkdtemp(), "pca.lsm")
>>> X = [[1.0, 2.0, 3.0], [2.0, 1.0, 4.0], [3.0, 4.0, 2.0], [4.0, 3.0, 1.0]]
>>> model = PCA(npc=2)
>>> model.fit(X)
>>> model.save(path)
>>> loaded = PCA()
>>> loaded.load(path)
>>> loaded.npc
2
>>> loaded.predict(X) == model.predict(X)
True

Low-level API

Thin ctypes wrappers around the C functions, working on raw C pointers. They are needed only to interoperate with other low-level code.

class libscientific.pca.PCAMODEL

C structure holding a fitted PCA model (low-level API).

Use PCA instead of accessing this structure directly. All fields are pointers to C matrices/vectors; convert them with libscientific.matrix.matrix_to_list() or libscientific.vector.dvector_tolist().

scores

Scores T, shape (n_objects, npc).

Type:

POINTER(MATRIX)

loadings

Loadings P, shape (n_features, npc).

Type:

POINTER(MATRIX)

dmodx

Distance of each object to the model (DModX), shape (n_objects, npc): column k is the distance after removing components 0..k.

Type:

POINTER(MATRIX)

varexp

Percentage of variance explained by each component, size npc.

Type:

POINTER(DVECTOR)

colaverage

Column means used for centering, size n_features.

Type:

POINTER(DVECTOR)

colscaling

Column scaling factors, size n_features (all 1.0 when scaling=0).

Type:

POINTER(DVECTOR)

libscientific.pca.pca_algorithm(m_input: ctypes._Pointer[mx.MATRIX], scaling: int, npc: int, mpca: ctypes._Pointer[PCAMODEL]) → None

Fit a PCA model with the NIPALS algorithm (low-level API, see PCA.fit()).

Parameters:

  • m_input (ctypes.POINTER(MATRIX)) – Training data, shape (n_objects, n_features).

  • scaling (int) – Column preprocessing, 0-5 (see PCA).

  • npc (int) – Number of components to compute (capped to n_features).

  • mpca (ctypes.POINTER(PCAMODEL)) – Model created with new_pca_model(); it is filled with the results.

Examples

>>> import libscientific.matrix as mx
>>> X = mx.new_matrix([[1.0, 2.0], [2.0, 1.0], [3.0, 4.0]])
>>> m = new_pca_model()
>>> pca_algorithm(X, 1, 2, m)
>>> m[0].scores[0].row, m[0].scores[0].col
(3, 2)
>>> del_pca_model(m); mx.del_matrix(X)
