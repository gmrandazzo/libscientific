Missing values

Miscellaneous utilities: the missing value marker.

Functions

libscientific.misc.missing_value()

Return the value that marks a missing data point in libscientific.

Data points equal to this value (within a tolerance) are skipped by the algorithms (PCA, PLS, statistics, …). In Python you can also pass float("nan"): NaN and infinite values are converted to this value by the C library. Non-numeric entries of lists (e.g. "NA") are converted to it when a matrix or vector is created.

Returns:

The missing value marker (99999999.0).

Return type:

float

Examples

>>> missing_value()
99999999.0
