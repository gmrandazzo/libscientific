PLS — Partial Least Squares regression

Partial Least Squares regression (PLS).

PLS models the relationship between a matrix of predictors X (n_objects x n_features) and a matrix of responses Y (n_objects x n_y) through nlv latent variables:

X = T @ P.T + E        Y = T @ diag(b) @ Q.T + F

T are the X scores (n_objects x nlv), P the X loadings (n_features x nlv), W the X weights used to compute the scores of new objects, U the Y scores, Q the Y loadings (n_y x nlv) and b the inner regression coefficients. Latent variables are computed one at a time with the NIPALS algorithm.

Most users only need the PLS class:

>>> from libscientific.pls import PLS
>>> X = [[1.0, 2.0, 0.5], [2.0, 1.0, 1.5], [3.0, 4.0, 1.0],
...      [4.0, 3.0, 2.5], [5.0, 5.0, 2.0], [6.0, 4.5, 3.5]]
>>> y = [[3.1], [3.9], [7.2], [7.8], [10.1], [10.9]]
>>> model = PLS(nlv=2, xscaling=1, yscaling=0)
>>> model.fit(X, y)
>>> y_pred, scores = model.predict([[3.5, 3.0, 2.0]], nlv_=2)
>>> round(y_pred[0][0], 2)
7.02

The functions after the class (new_pls_model, pls_algorithm, …) are the low-level ctypes wrappers of the C API.

class libscientific.pls.PLS(nlv: int = 2, xscaling: int = 1, yscaling: int = 0)

Partial Least Squares regression model (NIPALS algorithm).

Parameters:

  • nlv (int, default 2) – Number of latent variables to compute. It is capped to the number of features: after fit(), nlv holds the number actually computed.

  • xscaling (int, default 1) – Column preprocessing of X. Every option mean-centers the columns, then: 0 = no scaling, 1 = unit variance (autoscaling), 2 = root mean square, 3 = Pareto, 4 = range, 5 = level (see PCA for details).

  • yscaling (int, default 0) – Column preprocessing of Y, same options as xscaling. Predictions are always returned in the original units of Y.

nlv

Number of latent variables of the model.

Type:

int

xscaling, yscaling

The preprocessing options given at construction.

Type:

int

model

The underlying C model (low-level access, see PLSMODEL).

Type:

ctypes.POINTER(PLSMODEL)

Notes

  • Y is always 2D: one column per response. A single response is [[y1], [y2], ...].

  • The sign of each latent variable is arbitrary: scores, loadings and weights of a latent variable can change sign between platforms without changing the predictions.

  • Inputs can be lists of rows, numpy arrays or Matrix objects (see MatrixLike); results are Python lists.

Examples

>>> from libscientific.pls import PLS
>>> X = [[1.0, 2.0, 0.5], [2.0, 1.0, 1.5], [3.0, 4.0, 1.0],
...      [4.0, 3.0, 2.5], [5.0, 5.0, 2.0], [6.0, 4.5, 3.5]]
>>> y = [[3.1], [3.9], [7.2], [7.8], [10.1], [10.9]]
>>> model = PLS(nlv=2, xscaling=1, yscaling=0)
>>> model.fit(X, y)
>>> [round(v, 2) for v in model.get_exp_variance()]   # % of X variance per LV
[82.3, 17.47]

Predict with 1 and 2 latent variables at once (one column per latent variable for a single response):

>>> y_pred, t_scores = model.predict(X)
>>> [round(v, 2) for v in y_pred[0]]
[3.27, 3.42]

Predict new objects with 2 latent variables:

>>> y_new, _ = model.predict([[3.5, 3.0, 2.0]], nlv_=2)
>>> round(y_new[0][0], 2)
7.02
fit(x_input: libscientific.matrix.MatrixLike, y_input: libscientific.matrix.MatrixLike) → None

Fit the model on training data.

X and Y are preprocessed according to xscaling and yscaling, then nlv latent variables are extracted. Calling fit again replaces the previous model.

Parameters:

  • x_input (MatrixLike) – Predictors, shape (n_objects, n_features).

  • y_input (MatrixLike) – Responses, shape (n_objects, n_y): one column per response ([[y1], [y2], ...] for a single response).

Returns:

The model is updated in place.

Return type:

None

Examples

>>> model = PLS(nlv=5)
>>> model.fit([[1.0, 2.0], [2.0, 1.0], [3.0, 4.0], [4.0, 3.0]],
...           [[1.0], [2.0], [3.0], [4.0]])
>>> model.nlv        # capped to the number of features
2

get_beta_coefficients(nlv: int = 1) → list[float]

Return the regression coefficients of the model with nlv latent variables.

The coefficients B = W (P' W)^-1 b turn the PLS model into a linear equation on the preprocessed data:

(y - y_average) / y_scaling = sum_j B[j] * (x[j] - x_average[j]) / x_scaling[j]

so predictions can be computed without the model, e.g. with pls_beta_inference().

Parameters:

nlv (int, default 1) – Number of latent variables, from 1 to nlv.

Returns:

n_features coefficients, one per feature.

Return type:

list[float]

Raises:

ValueError – If the model has more than one response: the coefficients are computed for a single response only.

Examples

>>> X = [[1.0, 2.0, 0.5], [2.0, 1.0, 1.5], [3.0, 4.0, 1.0],
...      [4.0, 3.0, 2.5], [5.0, 5.0, 2.0], [6.0, 4.5, 3.5]]
>>> model = PLS(nlv=2)
>>> model.fit(X, [[3.1], [3.9], [7.2], [7.8], [10.1], [10.9]])
>>> len(model.get_beta_coefficients(2))
3
get_vip() → list[float]

Return the Variable Importance in Projection (VIP) of each feature.

VIP summarizes how much each feature contributes to explaining Y over all the latent variables of the model (S. Wold’s definition). The average of the squared VIP values is 1, so features with VIP > 1 are usually considered important and features with VIP < 0.8 candidates for removal.

Returns:

n_features values, one per feature.

Return type:

list[float]

Examples

>>> X = [[1.0, 2.0, 0.5], [2.0, 1.0, 1.5], [3.0, 4.0, 1.0],
...      [4.0, 3.0, 2.5], [5.0, 5.0, 2.0], [6.0, 4.5, 3.5]]
>>> model = PLS(nlv=2)
>>> model.fit(X, [[3.1], [3.9], [7.2], [7.8], [10.1], [10.9]])
>>> vip = model.get_vip()
>>> len(vip), round(sum(v * v for v in vip) / len(vip), 6)
(3, 1.0)

predict(x_input: libscientific.matrix.MatrixLike, nlv_: int | None = None) → tuple[list[list[float]], list[list[float]]]

Predict the responses of new objects.

Parameters:

  • x_input (MatrixLike) – Objects to predict, shape (n_new_objects, n_features), with the same features (same order) as the training data.

  • nlv_ (int, optional) – Number of latent variables to use, from 1 to nlv. If omitted, the predictions of every number of latent variables are returned side by side (see Returns).

Returns:

  • y_pred (list[list[float]]) – Predicted responses in the original units of Y.

    • With nlv_: shape (n_new_objects, n_y).

    • Without nlv_: shape (n_new_objects, n_y * nlv), where column n_y * k + j is response j predicted with k + 1 latent variables. For a single response, column k is the prediction with k + 1 latent variables.

  • t_scores (list[list[float]]) – X scores of the new objects, shape (n_new_objects, nlv).

Raises:

ValueError – If nlv_ is not between 1 and nlv.

Examples

Two responses, three latent variables:

>>> X = [[1.0, 2.0, 0.5], [2.0, 1.0, 1.5], [3.0, 4.0, 1.0],
...      [4.0, 3.0, 2.5], [5.0, 5.0, 2.0], [6.0, 4.5, 3.5]]
>>> Y = [[3.1, 0.2], [3.9, 0.9], [7.2, 0.8], [7.8, 1.9], [10.1, 1.7], [10.9, 2.8]]
>>> model = PLS(nlv=3)
>>> model.fit(X, Y)
>>> y_all, t = model.predict(X)
>>> len(y_all[0]), len(t[0])      # 2 responses x 3 LVs, 3 LVs
(6, 3)
>>> y_2lv, _ = model.predict(X, nlv_=2)
>>> len(y_2lv[0])                 # both responses, 2 LVs
2
>>> y_2lv[0] == y_all[0][2:4]
True
save(filepath: str) → None

Save the model to a file.

Parameters:

filepath (str) – Destination path. .sqlite3 or .db use the legacy SQLite format; any other extension (.lsm recommended) uses the binary libscientific model container.

Raises:

OSError – If the file cannot be written.

load(filepath: str) → None

Load a model saved with save(), replacing the current one.

The format is detected from the file content or the extension. After loading, nlv is set to the number of latent variables stored in the file; xscaling and yscaling are left unchanged (predictions use the stored column averages and scalings).

Parameters:

filepath (str) – Path of the model file.

Raises:

OSError – If a binary model file cannot be read.

Examples

>>> import os, tempfile
>>> X = [[1.0, 2.0], [2.0, 1.0], [3.0, 4.0], [4.0, 3.0]]
>>> model = PLS(nlv=2)
>>> model.fit(X, [[1.0], [2.0], [3.0], [4.0]])
>>> path = os.path.join(tempfile.mkdtemp(), "pls.lsm")
>>> model.save(path)
>>> loaded = PLS()
>>> loaded.load(path)
>>> loaded.predict(X) == model.predict(X)
True

libscientific.pls.pls_beta_inference(x_input: list[list[float]], **kwargs: list[float]) → list[list[float]]

Predict a single response from the beta coefficients only.

Useful to deploy a model as a simple linear equation, without the library or the full model. The result is the same as PLS.predict() with the same number of latent variables.

Parameters:

  • x_input (list[list[float]]) – Objects to predict, shape (n_objects, n_features).

  • **kwargs –

    All required:

    • x_averages, x_scaling: from PLS.get_x_averages() and PLS.get_x_column_scaling().

    • y_averages, y_scaling: from PLS.get_y_averages() and PLS.get_y_column_scaling().

    • beta_coeff: from PLS.get_beta_coefficients().

Returns:

Predictions, shape (n_objects, 1), in the original units of Y.

Return type:

list[list[float]]

Examples

>>> X = [[1.0, 2.0, 0.5], [2.0, 1.0, 1.5], [3.0, 4.0, 1.0],
...      [4.0, 3.0, 2.5], [5.0, 5.0, 2.0], [6.0, 4.5, 3.5]]
>>> model = PLS(nlv=2, xscaling=1, yscaling=0)
>>> model.fit(X, [[3.1], [3.9], [7.2], [7.8], [10.1], [10.9]])
>>> y_beta = pls_beta_inference([[3.5, 3.0, 2.0]],
...                             x_averages=model.get_x_averages(),
...                             x_scaling=model.get_x_column_scaling(),
...                             y_averages=model.get_y_averages(),
...                             y_scaling=model.get_y_column_scaling(),
...                             beta_coeff=model.get_beta_coefficients(2))
>>> y_model, _ = model.predict([[3.5, 3.0, 2.0]], nlv_=2)
>>> round(y_beta[0][0], 8) == round(y_model[0][0], 8)
True

Low-level API

Thin ctypes wrappers around the C functions, working on raw C pointers. They are needed only to interoperate with other low-level code.

class libscientific.pls.PLSMODEL

C structure holding a fitted PLS model (low-level API).

Use PLS instead of accessing this structure directly. All fields are pointers to C matrices/vectors/tensors; convert them with libscientific.matrix.matrix_to_list() or libscientific.vector.dvector_tolist().

With n objects, f features, n_y responses and nlv latent variables, the fields filled by pls_algorithm() are:

xscores, xloadings, xweights

T (n x nlv), P (f x nlv) and W (f x nlv).

Type:

POINTER(MATRIX)

yscores, yloadings

U (n x nlv) and Q (n_y x nlv).

Type:

POINTER(MATRIX)

b

Inner regression coefficients, one per latent variable.

Type:

POINTER(DVECTOR)

xvarexp

Percentage of the X variance explained by each latent variable.

Type:

POINTER(DVECTOR)

xcolaverage, xcolscaling, ycolaverage, ycolscaling

Column means and scaling factors of X (size f) and Y (size n_y).

Type:

POINTER(DVECTOR)

recalculated_y, recalc_residuals

Fitted Y of the training objects and their residuals, n x (n_y * nlv); column n_y * lv + j refers to response j with lv + 1 latent variables.

Type:

POINTER(MATRIX)

The remaining fields (``predicted_y``, ``q2y``, ``sdep``, ``roc_*``,
``yscrambling``, ...) are filled by the validation functions of the C
library (cross-validation, y-scrambling) and are empty after a plain fit.
